# 下一版优先级

## P0：参赛可演示

1. 接入专用中文 OCR，并输出真实文字框坐标与置信度；
2. 选择一个 1B–4B 的本地 OpenVINO 指令模型，完成字段候选提取；
3. 建立 100–300 份匿名商品资料评测集；
4. 增加人工确认页面，确认后单独生成正式事实文件；
5. 记录规则模式、OpenVINO 模式的速度、内存和准确率对比；
6. 增加 Qoder 一键演示流程。

## P1：增强创新点

1. 让证据依赖精确到文件内部块，而不仅是文件；
2. 增加型号/版本分流，防止多个 SKU 被错误合并；
3. 支持字段本体和行业模板；
4. 支持竞品资料隔离与来源权限；
5. 增加“为什么不能确认”的可解释决策路径。

## 暂时不要做

- 不做完整 PIM；
- 不做生图；
- 不做多人审批；
- 不做云端同步；
- 不做几十种平台规则；
- 不先做漂亮大前端再补核心准确率。
