# 人工修改、导出与回检一致性修复

日期：2026-09-17。基于 `f08356482ceb133c4d0586974b82b6b44ca9e5f2` 的修复；本文保留当时验证结果，现随 v2.0.1 统一交付，见[最终验证](STABLE_DELIVERY_20260917.md)。

## 本轮范围

修复第二轮审查的 6 个缺陷和 1 个适配缺口：

1. 净重改为“待定”、缺单位或无法解析的文字时，保存前明确拒绝，不改变原来的决定。
2. 将原文“材质待定”改成有效材质后，可以确认并导出；原文仍保留用于追溯。
3. 两种参数导出使用同一份当前事实和商品信息；人工模式只筛选人工批准的事实，不再导出旧型号。
4. 多商品本地简报按商品分组，同时保持每条事实的行号引用。
5. 防护等级简写与完整字段使用同一套商品、字段、口径、值和单位核对逻辑。
6. 文案明确写出另一个商品时，不再默认借用唯一已授权商品的参数。
7. 清晰的型号分段复用 SKU 的段落归属规则；段落之前的孤立证据仍待确认，表格行不向周围正文传播身份，也不自行发明变体。

无效值或保存失败的提示直接显示在操作窗口中，窗口不会关闭、输入不会丢失，用户可以直接修正后重试。

没有重写提取器或扩充产品字段白名单。上一轮其他提取规则问题不属于本轮“7 项修复”的完成声明。

后续按用户要求补修的三项提取根因及验证，单独记录于 [三项提取问题的根因修复](PARSER_ROOT_CAUSE_FIXES_20260917.md)，不混入本批历史测试数字。

## 实现边界

- `FactCandidate.value_input` 区分当前值输入与原始证据；不改变原文或候选快照结构。
- `value_review_reason` 同时用于人工保存和事实状态重建，人工批准不再豁免缺值/解析失败检查。旧的无效人工值重建时也不能直接变为已确认。
- 导出和授权引用复用当前商品信息。商品身份修正后，旧导出/字段包会失效；身份字段只参与本地摘要计算，不会因授权某个参数而额外披露未选择的型号或 SKU。
- 两种导出仍区分自动核验与人工批准，也保留对来源失效、冲突、模糊归属和部分交付的限制。
- 值语义版本从 4 升至 5。旧分析需要重新读取一次；保留人工决策审计，只有证据或读取结果变化的决定需要重新处理。

## 回归覆盖

新增 `tests/test_review_consistency.py`，17 个测试方法，包含同义写法和多种输入的子用例：

- 无效改值不修改决定；有效改值保存、重读、撤销、来源变化。
- 反向范围、缺单位、占位词、旧人工记录重建，以及未知文本字段仍可修改。
- 两种导出身份一致、同事实不重复、旧身份引用失效、多商品简报及行号。
- 实际授权与文案回检流程中的错商品、错条件；IP 简写/完整写法结论一致。
- ALPHA、AUDIT-A、A100 与不同分隔符；A1/A10 边界；正常输入电压不被当作商品。
- SKU/型号/Model 分段等价；孤立证据与同型号的变体歧义保持保守。

最终验证记录：

- 原 7 个独立复现用例：7/7 通过，最终重跑耗时 2.455 秒。
- 全量 Python 回归：744 个测试，741 个通过、3 个跳过，0 失败、0 错误；耗时 289.051 秒。
- 无窗口 Edge 浏览器回归：通过。覆盖采用、无效修改就地提示及保留输入、正确修改、撤销、跳过、授权、内容核对、4 种宽度、6000 条事实分页、读取时导航和失败提示。
- 就地错误提示完善后的补充回归：一致性与工作流服务 24 个测试全部通过，耗时 15.957 秒。
- `git diff --check`：通过。

默认 Playwright 浏览器二进制在本机缺失，改用已有 Edge 无窗口运行并通过，没有下载安装浏览器。

这些是缺陷回归，不是新增真实业务盲测，也不代表整个项目达到 100% 正确率。
