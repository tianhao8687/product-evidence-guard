## 模型限制

- 视觉语言模型可能漏掉文字、读错数字、无意归一表达或生成看似合理但不存在的
  内容。
- 模型给出的 confidence 是自我评估，不是校准概率。
- 模型生成的 bounding box 最多是近似位置；不能可靠定位时必须标记 unavailable，
  不能冒充 exact。
- 结构化 JSON 只能保证结构，不保证视觉识别或事实正确。schema 校验只是阻止
  非法结构进入证据图。
- 所选模型官方页面大小为 5.46 GB；本机 revision `f3d0bc7` 的 26 个必需
  payload 为 `5,462,515,610` bytes，包含 Hugging Face 元数据的目录为
  `5,462,526,140` bytes。官方没有公布这份精确工件的峰值内存要求。
- 一次成功 CPU 监测轮峰值 Working Set 约 10.83 GiB、Private Bytes 约
  6.96 GiB；这不是其他图片、并发量或机器的内存保证。
- 冻结 synthetic Benchmark 的 1.0 质量指标只适用于确定性生成的 30 图、10 文档
  数据集，不是授权真实商品资料上的准确率，也不是生产质量保证。
- OpenVINO 官方列出 Qwen3 VL 的 CPU/GPU 支持。本工作流中的 `GPU` 指 OpenVINO
  可见的兼容 Intel GPU，而不是 NVIDIA GPU。
- 公开入口默认 `AUTO`；只在 `FULL_DEVICE_NAME` 含 `Intel` 时自动选择 GPU，
  否则选择 CPU。显式设备会校验，NPU 会拒绝。
- 通用 OpenVINO VLM-on-NPU 能力不能证明
  `Qwen3-VL-8B-Instruct-int4-ov` 在某个具体 NPU 上可用。
- Named Pipe 父服务管理常驻模型 worker，已经用 `model_reused=true` 和热请求
  加载 0 秒证明同一模型跨请求复用。
- 真实 4 图推理期间，公开 `run.ps1 status` 已通过 Named Pipe 在 0.438 秒内返回
  `running` 和 `available_operations`，响应没有 fallback 字段。这证明状态查询
  可以在模型 worker 推理期间由父服务并发处理，不代表其他协议错误路径都已验证。

## 图片与 PDF 限制

- RapidOCR recognizer score 不是校准正确率。真实电池样本曾以 `0.95521` 把
  `1000mAh 3.7V` 读成 `11000mAh 3.7U`，所以 OCR 不单独裁决事实。
- OCR 检测框没有经过本项目人工坐标标定，报告仍保守标为 `approximate`。
- 生成式 VLM 与 OCR 都可能出错，二者不能替代人工确认。
- 反光、模糊、畸变、压缩、小字、艺术字体、多语言排版和遮挡都会降低质量。
- 文字版 PDF 使用确定性文字层。检测到图纸、曲线或大图的 mixed page 会保留
  文字层上下文并在需要时本地渲染；可靠大图区域可用 PDFium 做保守 ROI，旋转、
  坐标异常、区域分散或节省不足时回退整页。Raspberry Pi/TI 官方样本已验证；
  纯无文字层扫描 PDF 与恶意/边界 PDF 仍未完成真机验证。
- 文字层已经充分描述页面的 mixed PDF 会走 `ocr_observations`，保留 OCR 行和
  原页坐标但不调用 Qwen，也不生成产品事实。这能避免对曲线页做无意义的长推理，
  但不提供曲线逐点数字化；需要曲线坐标时仍须专门工具或人工核对。只有明确标签、
  重量/尺寸/数量/型号/材质/颜色白名单、足够置信度、合法单位和单值条件同时满足
  时，才可取消仅观察选择。电气/容量字段、低置信、未知单位、同一 OCR 行多值或
  输入/输出混写仍只保留观察，不调用 Qwen，也不生成候选。
- 普通商品图片可以在 OCR 安全检查失败时进入一次 Qwen 紧凑复核；schema 有效但
  没有安全候选的复核结果会安全结束，不重复 deep。只有无效或报错的复核输出才
  进入原有两步深度路径。
- OCR observations 只是带 recognizer score 与近似框的行级观察，不是
  FactCandidate，也不是准确率。当前不会把 PDF 曲线完整数字化为每个数值点；
  轴、刻度或图例被读到不等于曲线数据已恢复。
- OCR sidecar 会作为外部提供的证据使用；其准确率和坐标语义取决于生产者。
- 8 张公开真实样本只覆盖本次路由与延迟检查，不是准确率数据集；不可读、注入、
  倾斜、反光和大批量真实图片仍未形成完整评测。

## 文档解析限制

- TXT 与 Markdown 假定 UTF-8 或 UTF-8 with BOM。
- CSV 不自动推断任意编码或复杂表格公式。
- XLSX 读取单元格值；openpyxl 不执行公式计算。原生图表只结构化当前可解析的
  series 引用、类别和值；不支持的图表或外部数据源会保留问题记录，而不是猜测。
- DOCX/XLSX 内嵌的 PNG/JPEG/WebP/BMP 可提取并定位，其他媒体、复杂绘图、
  OLE/嵌入对象、页眉页脚和特殊阅读顺序不保证可干净映射。
- DOCX 和 PDF 的版式重建仍有限；PDF mixed page 检测是安全启发式，可能漏掉
  没有关键词、大图或足够矢量特征的视觉页。
- 4 份真实公开文档已完成原生解析测试，但两份大型 XLSX 是多产品/设备目录，
  当前没有通用的逐行产品 schema 映射；精确优先规则可能漏掉标题或叙述句中的
  参数，例如 Raspberry Pi PDF 标题中的 `45W`。
- 真实文档测试的完整样本哈希、修复前后结果和速度见
  [`REAL_DOCUMENT_EVALUATION.md`](REAL_DOCUMENT_EVALUATION.md)；它不是带标注的
  accuracy/recall 数据集。
- 密码保护、损坏或不受支持的文档可能被跳过或报告错误。
- 已有文件数、文件大小、页数、像素和总文字上限，但尚未通过恶意输入端到端验证。
  服务端对模型加载、每个文件和最终化阶段分别设置 300 秒心跳边界；边界超时时
  会终止该服务创建并精确跟踪的模型 worker。客户端另有 1 小时整请求上限。恶意
  文件的内存、磁盘和解析器压力仍需专门测试。

## 安全限制

- 本工具不是处理敌对文档的沙箱。
- ZIP/XML Office 格式和原生图片/PDF 解码器都有解析攻击面。
- 输入发现、发布和 Qoder 安装已经对 symlink/junction/reparse point/hardlink
  做失败关闭检查并纳入回归；这不是竞态、网络文件系统或管理员攻击下的完整沙箱。
- 提示词注入防护仍需要真实模型对抗测试。
- 依赖安装已经使用 hash-required 锁；模型 26 文件 SHA-256 清单已经生成但未签名。
  CycloneDX 1.5 SBOM、35 个锁定包的许可证元数据，以及实际 pypdfium2 wheel 的
  19 份 PDFium/依赖 notices 已完成；漏洞扫描、所有二进制传递依赖的完整许可证
  审计和模型清单签名仍待完成。
- 输出报告是明文，不提供加密、访问控制或安全删除。
- 不要以管理员身份运行，也不要接收不可信公开上传。

见 [`SECURITY.md`](../SECURITY.md)。

## 隐私限制

- 证据报告会有意保留来源片段、值、相对文件名、位置和哈希，可能含机密信息。
- 输出和缓存会一直保留，直到用户删除。
- Git ignore 只能降低误提交风险，不能阻止复制、同步、恶意软件访问或错误 Git
  命令。
- 项目没有遥测实现；35 个约 100 ms 的本地进程 TCP 状态采样未观察到外部 TCP，
  但尚未通过防火墙、数据包、DNS 或 UDP 抓取确认整个安装依赖栈零外连。
- Qoder 是独立宿主，有自己的账号、网络和隐私行为。本地 Skill 包装不能证明
  所有 Qoder 上下文都留在本机。

见 [`PRIVACY.md`](../PRIVACY.md)。

## 证据与决定限制

- 多个文件重复同一个值仍可能一起复制了上游错误。
- 一条候选只是证据，不是真相。
- 单位等价不能解决概念口径。净重、毛重、包装重量、单件数量和套装数量必须保持
  区分。
- “可能兼容”不是确认。例如“不锈钢”与“304 不锈钢”仍可能需要人工决定。
- 哈希失效能检测字节变化，但不能识别所有业务事件。供应商可能发布新版本，而某些
  受影响文件字节没有变化。
- 本地流程记录理由和时间，但不是企业身份、数字签名或审批系统。
- 应用不能判断来源是否已授权、是否最新或是否合法使用。

## 范围限制

当前项目不提供：

- 完整 PIM；
- 多用户权限、身份认证或审批流；
- 云同步或远程协作；
- 自动发布到电商平台；
- 图片生成或编辑；
- 强冲突中的自动真值选择；
- 模型训练或领域微调；
- 所有商品品类的保证识别率；
- 比赛入选或监管合规保证。

## 状态用语

状态字段只使用：

- **已完成：** 代码、文档或工件存在并已检查，不自动代表运行通过；
- **已验证：** 对应流程已经真实执行并留有证据；
- **待用户操作：** 需要登录、授权样本、发布或外部提交；
- **未完成：** 缺失，或尚未执行到足以形成验证结论。

离线环境变量推理与防火墙/抓包网络审计必须分开陈述，不能用前者替代后者。
