# 单位与跨行值完整性优化

本轮修复上一轮发现的两条根因，没有增加用户操作层或新依赖。界面继续只区分冲突、待确认、已确认；清楚且无冲突的单来源仍可自动确认。

## 修了什么

1. **单位不能一律小写。** 原先单位注册、数值转换和开放字段比较都可能折叠大小写，证据去重会进一步隐藏差异。现在换算只接受明确登记的大小写别名；陌生单位保留数字后符号的大小写，证据 ID 同步使用这条规则。本地文本模型不得在复制原文时改掉单位大小写。`mW` 与 `MW` 的不同含义依据 [BIPM 的 SI 前缀表](https://www.bipm.org/en/measurement-units/si-prefixes)，不是针对某一家资料补丁。
2. **一行结束不等于参数结束。** 明确对齐的值列可以接续下一行，遇到新标签、不同缩进或段落间隔就停止。同一个物理单元格内的换行合为完整值，不再只采用第一行。超过安全长度时报告未读全，不批准截断前缀。原文链接的定位框包含续行。
3. **保留影响含义的条件。** 交直流、尺寸轴顺序进入已有口径字段，不另建数据模型；界面显示“直流”“尺寸顺序：宽×高×深”。
4. **升级只需一个入口。** 旧规则生成的结果显示“更新已有结果”，读取更新前不能正式导出、部分导出或创建可用字段授权。原人工决定及审计不删除；重新读取后，没有变化的确认继续沿用，变化的值不能冒用旧确认。

没有新增模型调用、云端接口、第三方依赖或项目专用模板。SKU/型号的既有大小写不敏感身份规则保持不变，普通文字与排版空格也不因本次修复强制进入待确认。

## 回归与测试答案维护

- 新增 17 项单位、证据 ID、模型复制、内容回检、条件保留、续行边界和旧结果升级回归。
- 历史合成/公开改编测试的部分答案本身把 `W/A/GB/MHz/dB` 等写成了小写。本次根据各测试的输入文本修订为保留单位符号，增加 `gold_revision: unit-case-v2-exposed-regression`；GHz 支持和显式尺寸轴顺序也更新对应期望。没有使用生产归一化函数生成答案，也没有放宽独立评分器。
- 修订影响既有 `accuracy_cases`、`generalization_cases`、`public_source_cases` 及百包用例；原始历史版本仍在 Git 中。原件冻结答案、上一轮评分证据和历史报告保持不变。旧百包中的 `holdout` 标签是历史分组，不代表本轮仍然未见。
- 完整回归、隐藏浏览器交互、旧原件的 18 个重点单元格检查与依赖清单检查统一执行；最终结果记录于下方验收小节。

### 验收结果

- 全套 680 项：677 通过，3 项因 Windows 符号链接权限跳过，0 失败。
- 隐藏浏览器通过采用、修改、撤销、跳过、授权、内容回检、四种宽度及 6,000 条事实分页检查；未占用用户桌面。
- 既有 4 份原件均无运行错误，18 个预定重点单元格通过；这不是其余页面的完整正确率测量。
- 文档链接/交付材料 9 项通过；依赖清单检查通过，没有新增依赖。
- 初次回归确实发现并修正了新逻辑兼容问题与旧答案大小写问题；上面的结果来自最终完整重跑，不是省略失败项后的统计。

## 仍不能省略的下一步

**本轮不构成正常生产放行。** 当前仍有 29/183 个自动已确认输出不满足上述严格正确性要求，5 份文件都保留读取不完整提示。

- u-blox 的双栏横线表仍没有可靠绑定，修好 MHz 大小写也不能补上丢失的 Timepulse 字段名；该条继续判错。
- 电池的化学式下标、SSD 的测试标准/保修条件脚注还未完整关联；SSD 三种容量的 TBW 数值虽已恢复，不能因此把缺失脚注判为正确。
- 大块宣传说明仍可能误判为参数，部分多型号性能/重量表还会漏读或待确认。

后续优先按“页面区域 → 表格行/完整值 → 原文脚注关联”复用现有解析器完善绑定，再使用从未参与调试的原件和独立复核衡量效果；不应继续靠字段白名单、强制所有项人工确认，或无差别增加模型调用解决这些问题。
