# 本地生产版实施与放行标准

本轮分五批连续实施；五批完成前只做必要开发检查，不运行逐批回归、真实模型或压力测试。全部实施后统一验收，发现问题先定位共享根因，再修复和复测。**实现完成不等于生产放行。**

## 支持边界

- Windows 本机、单用户，CLI / WorkBuddy / 本地核验页面；不作为公网或多租户上传服务。
- 本地推理，原件不上传；支持 TXT、Markdown、CSV、JSON、DOCX、XLSX、PDF 和常见图片。
- 能明确绑定行列、商品和条件的内容自动处理；明确且无冲突的单来源事实仍可自动确认。
- 加密、损坏、超限、宏、公式缺少可靠结果、未能绑定的复杂表格必须明确报告，不能把“程序运行结束”显示为“完整交付”。
- 三类事实不变：冲突、待确认、已确认。读取问题按文件/表格聚合，不能生成一堆空的待确认事实。
- 默认完整导出有统一检查；用户可明确选择仅导出已确认部分，结果必须标明未完成范围。

## 五批实施

1. 支持范围、可复现验收契约、数据来源与放行标准。
2. 复用现有 SourceBlock / structured_rows：保留表格结构和定位，绑定商品/条件，记录读取缺口。
3. 统一交付检查和简洁处理入口，完整/部分导出明确区分。
4. 输入安全、源文件一致性、可恢复任务与升级/回退边界。
5. 回归和验收工具、数据清单、操作文档；完成后统一测试。

复用现有事实图、确认审计、来源散列和缓存。不引入第二套事实状态、向量库、云端推理或分布式任务平台。

## 统一验收

- 现有 100 包是已参与开发的回归数据，不能再次称为盲测。
- 新原件目标：60 包、至少 15 家供应商、10 个领域、3,000 条人工标注事实；40 包开发、20 包冻结留出。机器生成的标注不能算独立人工复核。
- 在声明支持范围内：已确认事实精确率 >= 99.5%，召回率 >= 98%，清晰事实自动确认率 >= 95%。逐格式、逐领域分别统计；不以总平均掩盖弱项。
- 严重漏冲突、跨商品误绑定、严重错误自动确认不能出现；这些指标必须有分母、预测和原件定位，不能只看通过包数。
- 功能/交互、旧状态迁移、源文件变化、中断恢复、重复请求、损坏文件、压缩炸弹、依赖锁定、持续批处理和资源限制统一验证。
- 独立人工复核、真实用户试用和目标机器持续稳定性证据不能由代码测试代替。未具备时明确标为“本地试运行”，不标“正常生产可用”。

## 版本与回退

升级前保存旧程序版本与整个输出目录的独立备份。不要覆盖原件；不要把旧来源的确认迁移到新散列。新版解析规则变更会使分析缓存失效，确认记录保留但重新校验来源。回退时使用旧程序及其对应输出备份，不能混用新旧状态。

公开资料只用于有出处的测试；脱敏/改写数据须标为改编或合成。未经许可的私有测试包及模型权重不提交 GitHub。

## 本轮实施记录

五批代码已连续接入，随后进入统一测试，不存在逐批跑全量回归的步骤。

- 第一批：本文件固定支持范围和放行要求。
- 第二批：PDF 几何位置与显式型号矩阵；CSV/Office/PDF 复用同一绑定契约。未能绑定的复杂布局形成读取缺口，不强行打平成事实。无边框多层表头仍可能需要 CSV/XLSX 补充，并未宣称所有 PDF 都已解决。
- 第三批：共享交付检查，单来源自动确认不变；部分导出必须明确选择，文件携带范围说明；界面按文件汇总读取问题。
- 第四批：Office 展开/XML/宏/单元格限制，来源读取前后散列，零候选文件版本检查，逐文件检查点、两代报告恢复、明确任务取消和配置冲突检测。
- 第五批：新增回归用例、独立证据放行工具及本地试运行手册。原件人工复核与真实用户证据留空，不能由实现者代签。

统一测试结果见[本轮验收报告](PRODUCTION_VALIDATION_20260916.md)；此处的“已接入”不是“已获生产放行”。
