CPU，走 `qwen_ocr_review`，`model_reused=false`，每次产出 2 个候选且无错误。

| 3 | 25.5298 s | 4.2892 s | 30.8354 s |

**4.4680 s**，范围 **4.2162–4.8985 s**。这些是单机、单样本的三次分布，不是对所有
机器或所有图片的延迟承诺。可公开的逐次哈希和统计见

## 本地进程 TCP 采样

另一次独立冷启动中，对公开客户端进程、`server-state.json` 记录的本地服务 PID 及已发现
子进程进行约 100 ms 间隔的 TCP 状态采样。35 个观察周期内，在 `Established`、`SynSent`
和 `SynReceived` 状态中没有观察到外部 TCP 连接。该次客户端返回 `exit_code=0`、标准错误
为 0 字节，分析耗时 27.9003 s，模型加载 4.3332 s，产出 2 个候选且无错误。

这项记录的边界必须保留：它不是防火墙阻断，也不是数据包、DNS 或 UDP 抓取，不能证明
Qoder 宿主或整个依赖栈“完全零外连”或可用于 air-gapped 环境。可公开的观察范围、结果和
工件哈希见 [`network-tcp-observation-20260805.json`](network-tcp-observation-20260805.json)。
